# One User, One Agent

> **Status: in progress.** Implemented so far: ingestion (deduplication + corrected event time), the data quality
> report, profile and catalogue loading, the per-viewer fact resolver, the goal planner and the intervention planner. The one-command replay will be added once the agent loop exists. This README is updated as work progresses.

An agentic system that gives every viewer of a regional-dialect OTT platform one dedicated agent. On each app open the
agent chooses one measurable goal, decides what to change (home page, one message, or nothing) from evidence it can
cite, verifies the decision independently, publishes within the latency budget, and later judges honestly whether it
helped, measured against a randomized holdout.

## Setup

Requires Python ≥ 3.10 and no runtime dependencies ([doc/techstack.md](doc/techstack.md)). The data pack is expected
next to this folder at `../one_user_one_agent_pack/`.

```bash
# with uv
uv venv --python 3.10 .venv && uv pip install --python .venv/bin/python -e '.[dev]'
# or with pip
python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
```

Load the 30-day history and write `sample_run/data_quality_report.json`:

```bash
.venv/bin/python -m ott_agent load --pack ../one_user_one_agent_pack --out sample_run
```

## Inputs

The data pack lives next to this repo at `../one_user_one_agent_pack/` and is **read-only**. Only the pack is valid
evidence about viewers and titles. The pack is treated as personal data and is never sent to services that retain or
train on it.

## Model provider

The default is a **mock/replay provider**: no API key is needed. An optional local model via Ollama can be enabled
([D-003](doc/decisions.md)).
